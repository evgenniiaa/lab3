## Домашнее задание к работе 3 (вар.32)
### Условие задачи
Написать и отладить программу пересчета мегаджоулей в
килокалории и киловатт\час
### 1. Реализация программы
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

zadanie1() {
    double mj;    // мегаджоули
    double kcal;  // килокалории
    double kwh;   // киловатт·часы

    printf("Введите количество мегаджоулей (МДж): ");
    scanf("%lf", &mj);

    kcal = mj * 1000000.0 / 4186.8;
    kwh = mj * 1000000.0 / 3600000.0;

    printf("%.3lf МДж = %.3lf ккал\n", mj, kcal);
    printf("%.3lf МДж = %.3lf кВт·ч\n", mj, kwh);
}
int main() {
    setlocale(LC_CTYPE, ".UTF-8");
    zadanie1();
    return 0;
}
```

### 2. Результат работы программы
```
Введите количество мегаджоулей (МДж): 154
154.000 МДж = 36782.268 ккал
154.000 МДж = 42.778 кВт·ч
```
